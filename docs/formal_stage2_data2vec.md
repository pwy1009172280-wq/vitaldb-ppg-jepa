# Stage 2 formal data2vec-style PPG baseline

This is a documented data2vec-style adaptation for single-channel preprocessed PPG, not an exact Fairseq reproduction. The student embeds `[B,1,5000]`, replaces contiguous temporal patch spans with a learned mask token, preserves original absolute positions, and runs the full token sequence through the online encoder and linear latent head. A separate EMA teacher receives the full unmasked sequence. It aggregates a configurable uniform mean of the last K contextual Transformer block states and applies non-affine feature-wise LayerNorm. Smooth L1 regression is computed only at masked positions.

The teacher is frozen/eval-mode, excluded from the optimizer, and updated only by an explicit `ema_update(momentum)` call after a future successful optimizer step. Mask ratio, span length, K, EMA momentum, and Huber beta are configurable in `configs/smoke/data2vec.yaml`. The module has no device/path assumptions and its normal PyTorch state dict contains student, teacher, mask token, and prediction head for later `train_ssl.py` and Slurm integration. Benchmark timing prototypes are unrelated and are not imported.

Formal training supplies an explicit CPU `torch.Generator` for masking. The same generator state reproduces the same mask sequence; resulting boolean masks are placed on the model/input device. Future checkpointing must save and restore this CPU generator state. `generator=None` is acceptable only for smoke/debug use, not reproducible formal training. The current simple Python per-sample loop partitions fixed temporal blocks, randomizes block order, and prefix-truncates the final selected block; it may be benchmarked or vectorized before full-scale training.
